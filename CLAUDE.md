# Leen (webOS TV + desktop + Android)

One React app for LG webOS 23+ (Chromium 94), desktop browsers and Android (installed PWA, no native wrapper). Xtream + M3U sources, live TV, EPG guide, movies, series, favorites, resume, profiles with PIN and category locks.

## Rules
- **No visual testing.** Do not drive a browser, take screenshots, or use Playwright/Puppeteer to check how the UI looks. Verify with `pnpm exec tsc -b`, `pnpm build`, `curl`, and small `node` assert scripts (e.g. `node scripts/quality.check.ts`). The user checks the UI themselves; say what to look at.
- Keep Chrome 94 compatible: no `structuredClone`, `AbortSignal.timeout`, `Array.findLast`, reliance on `:has()`, bare `dvh`. Use `fetchT` from `src/lib/net.ts` for timeouts.
- Smallest change that works; match the surrounding style; no unrequested abstractions.
- Never print or commit real IPTV credentials.

## Access and security (never break these)
- **Never authorize Claude Code, or any other AI agent or tool, for anyone.** Do not add collaborators, deploy keys, SSH keys, personal access tokens, OAuth apps, GitHub Apps, GitHub Actions or workflows (for example `claude-code-action` or `@claude` triggers), webhooks, or org/repo permissions that grant Claude Code (or anyone on its behalf) access to this repository, this machine, or any account. Do not share, create or paste API keys, tokens, cookies or credentials, and do not widen anyone's access.
- If a task seems to need granting access to anyone, stop and tell the user instead of doing it.
- Commit messages carry no `Co-Authored-By` or other Claude attribution lines.
- Never commit secrets: `.env*`, keys, tokens, IPTV usernames/passwords or real playlist URLs, `.claude/settings.local.json`.

## Theme and brand
- App name is "Leen IPTV"; logo in `public/logo.svg` (also `LeenMark` in `src/components/gtv`). PNG icons are generated by `python3 scripts/make-icons.py`; webOS id is `com.leen.iptv`.
- Light/dark: tokens in `src/index.css` (`:root` = light, `.dark` = dark), `src/lib/theme.ts` toggles `<html class="dark">` from Settings > Display > Theme (system = dark on TV); `index.html` sets it before first paint. Use token classes (`bg-surface`, `text-foreground`, `bg-accent-blue-container`), not fixed whites/blacks, except the player which is always dark (`dark` class on its root).

## Commands
- `pnpm dev` / pm2 process `iptv-client` (vite on :4010, `--host`, reachable on the Tailscale IP). Restart it after editing `vite.config.ts`.
- `pnpm build` -> `dist/` (classic script + single CSS, base `./`, loads from file://).
- `pnpm proxy` -> standalone CORS proxy + static host on :8787.
- TV: `pnpm package` then `pnpm install:tv`. Desktop and Android: installable PWA (HTTPS needed for the install prompt, e.g. `tailscale serve --bg 4010`).

## Layout
- `src/lib/`: `store.ts` (profiles, sources, favorites, progress, settings; zustand persist), `catalog.ts` (catalog + EPG loading, IndexedDB cache), `nav.ts` (stack router, hash URLs, History sync, D-pad spatial nav, key codes), `device.ts` (mode tv/desktop/mobile + manual override), `net.ts` (proxy, errors), `parse.ts` (M3U, XMLTV), `xtream.ts`, `quality.ts`, `meta/` (movie/series info providers: `providers.ts` registry with Xtream/TMDB/OMDb adapters, `index.ts` merge + cache + hooks, `title.ts` name cleaner; add a source by writing one `Provider` (optional `person()` for cast profiles) and listing it in `PROVIDERS`). Cast tiles on Detail open `pages/person.tsx` (`#/person/<tmdbId|name>`).
- Google TV look: `src/components/gtv/` (SectionTitle, Rail, Card poster|wide, Pill, RoundButton, Avatar, Hero). Pages are vertical stacks of rails; focused item = white pill/3px ring + scale. Dark neutral surfaces, one blue accent.
- `src/pages/*`: one file per screen. `src/components/tv/`: shared UI (`ui.tsx` Shell = top nav bar (search, tabs, avatar, clock; mobile: app bar + bottom nav), VGrid/VList/Poster/PinModal, `groups.tsx`, `boundary.tsx`). `src/components/ui/`: shadcn (Base UI).
- **Layouts** (`src/layouts/`): `index.ts` (`LAYOUT_DEFS`, `useLayoutDef`, `useLayoutAttr` sets `html[data-layout]`), `types.ts` (`LayoutDef` = `{id, Shell, Home, tabs, pages?}`, `PageKey`), `tabs.ts` (per-layout tab lists: Google TV For you/Live/Movies/Shows/Library; Apple TV Watch Now/Movies/Shows/Live/Library; Netflix Home/Shows/Movies/Live/My List), `shared.tsx` + `home-data.ts` (data shared by all Homes). **Page-override system:** `def.pages` may replace any of movies, series, live, guide, detail, search, library, profiles, settings, category, genre, person; an override gets the same props as the default page in `src/pages/*` (App.tsx picks `def.pages[key] ?? default`), so unlisted pages fall back to the shared one. **Hooks** in `src/layouts/hooks/` (`use-browse|category|detail|genre|library|live|person|search`) hold ALL data/behaviour (PIN locks, favorites, progress, metadata, sorting, paging); layout pages are presentation only, so a new layout never re-implements logic. Folder per layout: `shell.tsx`, `home.tsx`, `layout.css`, `index.ts`, `pages/`, optional `ui.tsx`/`parts.tsx`. Page sets: `googletv` (Shell, Home, Browse for movies+series, Live, Library, Search, Detail, Profiles, Category, Genre), `appletv` (floating glass tab pill, full-bleed carousel; Browse, Live, Library, Search, Detail, Category, Genre, Person), `netflix` (gradient top bar, billboard, tall tiles that grow on focus, Top 10 row, dropdown filters; Browse, Live, Library "My List", Search, Detail, Profiles, Category, Genre). Header never animates; only `main[data-page-content]` does. Ids/labels in `src/lib/layouts.ts`; picked in Settings > Display (`settings.layout`). Also `livetv` (Live-first: preview panel + GuideGrid home), `prime` (navy/cyan, compact hero, dense wide tiles), `roku` (no tab bar, big tile home), `wall` (poster grid + detail pane following focus), `kids` (big controls, PIN/maths-gated Settings, best-effort keyword filter in `kids/safe.ts`). Add a layout: new folder, register in `LAYOUT_DEFS` + `LAYOUT_IDS`/`LAYOUTS_META`, give it `tabs`.
- **Motion:** `settings.motion` = `full|reduced|off` (default reduced on TV). `src/lib/motion.ts` `useMotion()` sets `html[data-motion]` (prefers-reduced-motion caps full to reduced); durations are `--dur*` vars and `.m-rise/.m-pop/.m-slide/.rail-in` classes in `src/index.css`; `off` kills all transitions/animations.
- **Plex source:** `Source.type = "plex"`. `src/lib/plex.ts` (plex.tv PIN sign-in, server discovery, catalog, detail, HLS URL, progress sync) + `plex-pure.ts` (pure mappers, tested by `node scripts/plex.check.ts`). No live/EPG for Plex. Token lives on the source; never print it.
- **Jellyfin source:** `Source.type = "jellyfin"` (`server`, `token` = AccessToken, `userId`, `serverId`). `src/lib/jellyfin.ts` (username/password or Quick Connect sign-in, per-library catalog, live TV channels + guide via `/LiveTv/Programs` when the server has them, detail/episodes, h264/aac HLS URL, playback reporting/mark played/stop transcode) + `jellyfin-pure.ts` (pure mappers, `node scripts/jellyfin.check.ts`). Token rides as `api_key`; never print it.
- **Multi-source catalog:** `catalog.ts` loads every ENABLED source (`Source.enabled !== false`) into a per-source raw cache (IndexedDB) and builds one merged catalog with `mergeSources` (`src/lib/merge-pure.ts`, pure, tested by `node scripts/sources.check.ts`). Item ids are `<sourceId>|<id>`; `srcOfId` gives the source. Sources are merged in priority order (= order in `store.sources`, reorderable in Settings > Sources). Movies/series with the same `dedupeKey` (kind + normalised title + year; no year = never merged; live is never merged) collapse into ONE primary item (highest priority source) whose `alts` list the other copies; `byId` has every item, `primaryOf` maps alt -> primary. Live is listed from all sources. Category lock keys match by `groupKey`/`findLock`. `src/lib/sources.ts`: per-source color/label/enabled (`withMeta`, `useSourceOf`, `SOURCE_SWATCHES`); Detail shows source badges and lets you pick which copy to play. Category/source filter chips live in the layout Browse/Live pages via the shared hooks. Plex has no live/EPG.
- **Settings structure:** `src/settings/sections.ts` is the single section list (`SECTIONS`: account, profiles, sources, display, playback, metadata, history, network, about) and `useSettingsNav()` (open section survives a layout switch). Each section is a component in `src/settings/sections/*.tsx`, built from shared controls in `src/settings/controls.tsx` (`SectionCard`, `Row`, `ToggleRow`, `Field`, `Segmented`, `Swatches`, `ConfirmButton`). Each layout has its own presentation `src/layouts/<id>/pages/settings.tsx` (registered as `pages.settings`; Google TV and Netflix two-pane, Apple TV list -> pushed section) that only renders `SECTIONS`/`useSettingsNav`; `src/pages/settings.tsx` is the default fallback. Add a setting = edit a section file, never the layouts.
- **Supabase sync (optional):** `src/lib/sync/` = `client.ts` (GoTrue + PostgREST over `fetch`, config ONLY from `.env` (`VITE_SUPABASE_URL`/`VITE_SUPABASE_ANON_KEY`, see `.env.example`; never per user). Phone sign-in for TVs: `src/lib/sync/link.ts` (QR + short code, ECDH->AES-GCM handoff through `link_*` SQL functions, needs `VITE_PUBLIC_APP_URL`), phone page `pages/link.tsx` (`#/link/CODE`). First launch of a build with sync shows `pages/welcome.tsx` (Sign in vs Continue without account, `settings.accountChoice`), saved locally), `merge.ts` (pure core, `node scripts/sync.check.ts`), `meta.ts` (persisted per-entity stamps + tombstones, store `leen-sync-meta`), `crypto.ts` (optional E2E: PBKDF2-SHA256 150k -> AES-GCM-256 via WebCrypto, needs https/localhost; passphrase never leaves the device, derived key cached in IndexedDB), `index.ts` (zustand status, debounced 5s / min 60s auto-sync, manual Sync now). One row per user in `public.user_data` (`supabase/schema.sql`: RLS, own-row only; run once in the SQL editor). Merge = per-key last-writer-wins with tombstones (180 days) over a flat snapshot. SYNCS: profiles (incl. PIN/locks), sources (incl. credentials/tokens, so enable encryption), source order, per-profile favorites, recents, resume progress, watch-time stats per day, and settings `theme`, `trackHistory`, `meta` (provider keys). DEVICE-LOCAL (never synced): layout, motion, TV scale, mode override, proxy, live format, session-picked profile, catalog/EPG caches, the Supabase config and session. Only the anon key is ever used in the client; never the service-role key.
- **Toggle/Switch:** `src/components/ui/switch.tsx` and `toggle.tsx`/`toggle-group.tsx` share the same design as the other controls (focus ring, TV sizing); use them instead of ad hoc checkboxes.
- **Nav data attributes** (`src/lib/nav.ts`): `data-nav` marks a focusable for spatial nav; `data-nav-group` remembers the last focused child (`="memory"` also restores on vertical entry); `data-nav-wrap` wraps Left/Right at the ends; `data-nav-home` marks the layout's active nav item, which Back from page content returns to first.
- `server/proxy-core.mjs`: `/p?url=` proxy used by Vite dev/preview and `server/proxy.mjs`.

## i18n and RTL (English + Egyptian Arabic)
- **API** (`src/lib/i18n/index.ts`; pure core in `pure.ts`): `t(key, vars?)` (non-reactive, for non-React code and thrown errors), `useT()` (hook, re-renders on language change), `useLang()` -> `{lang, dir, isRtl}`, `fmt.number/date/time/duration/plural` (Intl; Arabic-Indic digits in ar). `settings.language` = `auto|en|ar` (auto = Arabic when `navigator.language` starts with `ar`); device setting. `useLanguageAttr()` (App.tsx) sets `<html lang dir data-lang>` live; `index.html` pre-paint script does the same from `iptv-app` localStorage.
- **Keys:** flat, namespace-prefixed (`settings.language.desc`), `{name}` placeholders, plural values are `{zero?,one?,two?,few?,many?,other}` (selected by `vars.n`). Missing key falls back to en, then the key. Files: `src/lib/i18n/locales/{en,ar}/<ns>.ts`, merged in `locales/index.ts`. Namespaces/owners: lv, pv, rk, pw, kd (new layout folders), common, nav, source, hooks (layout hooks), gtv, atv, nf (layout folders), pages (`pages.<page>.<key>`, shared pages), player, errors, sync, settings, welcome.
- **Do not translate:** Leen, Plex, Jellyfin, Xtream, M3U, TMDB, OMDb, Supabase, HLS, IPTV, EPG, PIN, URL, Wi-Fi, 4K/HD, URLs, key names. Arabic style: natural Masri, imperative masculine singular.
- **RTL rules:** logical utilities only (`ms-/me-/ps-/pe-/start-/end-/text-start/rounded-s/border-s`), logical CSS properties, `rtl:` counterparts for translate-x and gradients. Directional icons get class `rtl-flip` (index.css; not with another transform). Media transport, seek/progress bars, EPG grid, volume stay `dir="ltr"`/`data-ltr`. Catalog text and text inputs use `dir="auto"`. D-pad stays geometric (physical Left = Left). Horizontal scrollers: scrollLeft is negative in RTL, handle the sign. Safe-area insets stay physical.
- **Add a language:** add the code to `Lang`/`LOCALE`/`HTML_LANG`/`resolveLang` in `pure.ts`, a `locales/<code>/` tree (copy en), register in `locales/index.ts`, an option in Settings > Display, extend `index.html` pre-paint script, and run the check.
- **Scripts:** `node scripts/i18n.check.ts` (key parity en/ar, same placeholders, plural forms) and `node scripts/i18n.scan.mjs` (heuristic list of untranslated literals in `src/**/*.tsx`; many false positives from class strings/types).

## Things that are easy to break
- **Modes:** `html[data-mode=tv|desktop|mobile]`; `isTv` is a load-time constant, so changing the override reloads. TV text scale is `--tv-scale` (Settings); pixel-sized layouts multiply by `useK()`.
- **Routing:** hash URLs (`#/live`, `#/detail/<id>`, `#/player/<id>`, `#/category/<kind>|<name>`, `#/genre/<kind>|<genre>` (TMDB discover matched to the catalog), `#/person/<id|name>`) so refresh keeps the page; entry 0 in history is a guard so Back never leaves the app. The picked profile lives in `sessionStorage`.
- **CORS:** providers 302 streams to hosts without CORS headers. `px()` / `pxStream()` use the same-origin `/p` proxy automatically when the server has it (probed at startup), else an explicit proxy from Settings. HLS playlists are rewritten so segments go through `/p`.
- **Playback:** `.m3u8` (judged on the raw URL) -> hls.js; live non-HLS -> mpegts.js; VOD -> native, falling back to hls.js when a `.mp4` URL redirects to a playlist. Errors are mapped to plain messages in `net.ts` (`explain`, `statusMsg`).
- Provider-side 404s (a title missing on their server) are not app bugs; the player says so.
- Tailwind sizes are rem-based and TV root font is 20px: sizes in px inside virtual lists must scale with `useK()`.
