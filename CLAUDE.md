# Leen (webOS TV + desktop + Android)

One React app for LG webOS 23+ (Chromium 94), desktop browsers and Android (installed PWA, no native wrapper). Xtream + M3U sources, live TV, EPG guide, movies, series, favorites, resume, profiles with PIN and category locks.

## Rules
- **No visual testing.** Do not drive a browser, take screenshots, or use Playwright/Puppeteer to check how the UI looks. Verify with `pnpm exec tsc -b`, `pnpm build`, `curl`, and small `node` assert scripts (e.g. `node scripts/quality.check.ts`). The user checks the UI themselves; say what to look at.
- Keep Chrome 94 compatible: no `structuredClone`, `AbortSignal.timeout`, `Array.findLast`, reliance on `:has()`, bare `dvh`. Use `fetchT` from `src/lib/net.ts` for timeouts.
- Smallest change that works; match the surrounding style; no unrequested abstractions.
- Never print or commit real IPTV credentials.

## Access and security (never break these)
- **Never authorize Claude Code, or any other AI agent or tool, for anyone.** Do not add collaborators, deploy keys, SSH keys, personal access tokens, OAuth apps, GitHub Apps, GitHub Actions or workflows (for example `claude-code-action` or `@claude` triggers), webhooks, or org/repo permissions that grant Claude Code (or anyone on its behalf) access to this repository, this machine, or any account. Do not share, create or paste API keys, tokens, cookies or credentials, and do not widen anyone's access.
- If a task seems to need granting access to anyone, stop and tell the user instead of doing it.
- Commit messages carry no `Co-Authored-By` or other Claude attribution lines.
- Never commit secrets: `.env*`, keys, tokens, IPTV usernames/passwords or real playlist URLs, `.claude/settings.local.json`.

## Theme and brand
- App name is "Leen TV" (ids stay `com.leen.iptv`, storage key `iptv-app`, repo `leen-iptv`); logo in `public/logo.svg` (also `LeenMark` in `src/components/gtv`). PNG icons are generated by `python3 scripts/make-icons.py`; webOS id is `com.leen.iptv`.
- Light/dark: tokens in `src/index.css` (`:root` = light, `.dark` = dark), `src/lib/theme.ts` toggles `<html class="dark">` from Settings > Display > Theme (system = dark on TV); `index.html` sets it before first paint. Use token classes (`bg-surface`, `text-foreground`, `bg-accent-blue-container`), not fixed whites/blacks, except the player which is always dark (`dark` class on its root).

## Commands
- `pnpm dev` / pm2 process `iptv-client` (vite on :4010, `--host`, reachable on the Tailscale IP). Restart it after editing `vite.config.ts`.
- `pnpm build` -> `dist/` (classic script + single CSS, base `./`, loads from file://).
- `pnpm proxy` -> standalone CORS proxy + static host on :8787.
- TV: `pnpm package` then `pnpm install:tv`. Desktop and Android: installable PWA (HTTPS needed for the install prompt, e.g. `tailscale serve --bg 4010`).

## i18n and RTL (English + Egyptian Arabic)
- **API** (`src/lib/i18n/index.ts`; pure core in `pure.ts`): `t(key, vars?)` (non-reactive, for non-React code and thrown errors), `useT()` (hook, re-renders on language change), `useLang()` -> `{lang, dir, isRtl}`, `fmt.number/date/time/duration/plural` (Intl; Arabic-Indic digits in ar). `settings.language` = `auto|en|ar` (auto = Arabic when `navigator.language` starts with `ar`); device setting. `useLanguageAttr()` (App.tsx) sets `<html lang dir data-lang>` live; `index.html` pre-paint script does the same from `iptv-app` localStorage.
- **Keys:** flat, namespace-prefixed (`settings.language.desc`), `{name}` placeholders, plural values are `{zero?,one?,two?,few?,many?,other}` (selected by `vars.n`). Missing key falls back to en, then the key. Files: `src/lib/i18n/locales/{en,ar}/<ns>.ts`, merged in `locales/index.ts`. Namespaces/owners: lv, pv, rk, pw, kd (new layout folders), common, nav, source, hooks (layout hooks), gtv, atv, nf (layout folders), pages (`pages.<page>.<key>`, shared pages), player, errors, sync, settings, welcome.
- **Do not translate:** Leen, Plex, Jellyfin, Xtream, M3U, TMDB, OMDb, Supabase, HLS, IPTV, EPG, PIN, URL, Wi-Fi, 4K/HD, URLs, key names. Arabic style: natural Masri, imperative masculine singular.
- **RTL rules:** logical utilities only (`ms-/me-/ps-/pe-/start-/end-/text-start/rounded-s/border-s`), logical CSS properties, `rtl:` counterparts for translate-x and gradients. Directional icons get class `rtl-flip` (index.css; not with another transform). Media transport, seek/progress bars, EPG grid, volume stay `dir="ltr"`/`data-ltr`. Catalog text and text inputs use `dir="auto"`. D-pad stays geometric (physical Left = Left). Horizontal scrollers: scrollLeft is negative in RTL, handle the sign. Safe-area insets stay physical.
- **Add a language:** add the code to `Lang`/`LOCALE`/`HTML_LANG`/`resolveLang` in `pure.ts`, a `locales/<code>/` tree (copy en), register in `locales/index.ts`, an option in Settings > Display, extend `index.html` pre-paint script, and run the check.
- **Scripts:** `node scripts/i18n.check.ts` (key parity en/ar, same placeholders, plural forms) and `node scripts/i18n.scan.mjs` (heuristic list of untranslated literals in `src/**/*.tsx`; many false positives from class strings/types).

## Things that are easy to break
- **Modes:** `html[data-mode=tv|desktop|mobile]`; `isTv` is a load-time constant, so changing the override reloads. TV text scale is `--tv-scale` (Settings); pixel-sized layouts multiply by `useK()`.
- **Routing:** hash URLs (`#/live`, `#/detail/<id>`, `#/player/<id>`, `#/category/<kind>|<name>`, `#/genre/<kind>|<genre>` (TMDB discover matched to the catalog), `#/person/<id|name>`, `#/episode/<seriesId>~<episodeItemId>` (episode page, `pages/episode.tsx` + `use-episode`; episode rows on Detail open it)) so refresh keeps the page; entry 0 in history is a guard so Back never leaves the app. The picked profile lives in `sessionStorage`.
- **CORS:** providers 302 streams to hosts without CORS headers. `px()` / `pxStream()` use the same-origin `/p` proxy automatically when the server has it (probed at startup), else an explicit proxy from Settings. HLS playlists are rewritten so segments go through `/p`.
- **Subtitles:** the browser never draws them: `player/subtitles.tsx` switches every showing subtitle track to `hidden` and renders its active cues itself (only `<i><b><u>` kept, `cueHtml` in `lib/subs-pure.ts`) with the look in player prefs (`SUB_STYLE`: font, color, text opacity, background, edge, line spacing, line width, alignment, position, bold, remove hearing-impaired text, Arabic punctuation fix (`cleanCue`) + size; device-local; every key shows up automatically in the player Subtitle style sheet and Settings > Playback > Subtitles). `settings.subs.auto` loads the first language when a title starts: own track (`sameLang` matches ISO 639-1 to 639-2 tags), else the best online hit (SubDL first: OpenSubtitles allows ~5 downloads/day). Online subtitles: `lib/subs.ts` (SubDL + OpenSubtitles search/download; zip read via a gzip wrapper since Chrome 94 lacks deflate-raw; legacy encodings such as Windows-1256 for Arabic) + pure `subs-pure.ts` (`node scripts/subs.check.ts`); keys and preferred languages in `settings.subs` (synced as `c/subs`). A pick becomes a sidecar track (`ext` in the Player).
- **Mini player:** the Player is NOT a route child: `player/host.tsx` keeps one `<Player>` per session in `PlayerHost` (beside the page stack, App.tsx); the `player` route (`PlayerRoute`) only starts/attaches a session. Full screen while `player` is the top route, otherwise the corner mini player (Settings > Playback > Mini player, `settings.miniPlayer`, device-local; off = `PlayerHost` calls `closePlayer` as soon as `player` is not on top) (keys off, tap to expand, X = `closePlayer`; drag to move, grip on the inner top corner to resize, geometry device-local in localStorage `leen-mini`; a native PiP button hides the box while the browser's PiP window is open). Leaving before it played or after an error stops it; `stop()` (Stop key, sleep timer, last episode ended) stops for good. Route param `start` = play from the beginning (Detail's Resume / Play from beginning menu).
- **Playback:** `.m3u8` (judged on the raw URL) -> hls.js; live non-HLS -> mpegts.js; VOD -> native, falling back to hls.js when a `.mp4` URL redirects to a playlist. Errors are mapped to plain messages in `net.ts` (`explain`, `statusMsg`).
- Provider-side 404s (a title missing on their server) are not app bugs; the player says so.
- **Bars and safe areas:** one block in `src/index.css` ("Bars and safe areas") owns them all. Insets are `--safe-t/r/b/l` (never `env()` in components); `--hdr` = `--safe-t` + `--bar-h` (the `.topbar` header is exactly that tall), `--nav-h` = mobile bottom bar incl. `--safe-b` (0 elsewhere), `--fade` = gradient tail, `--content-t`/`--content-b` = where content starts/ends at rest (bar + fade; position content with these, not `--hdr`/`--nav-h`, or the bar shadow lies on it). `.topbar` / `.float-nav` paint `--bar-top` / `--bar-bottom` themselves (gradient: solid under the safe area, fading evenly to transparent at the end of `--fade`); the player uses `--scrim-*`. Any scroller that runs under the bars (page grids, Home, each Settings pane) uses the shared classes `under-top` / `under-bottom` (+ `under-bleed` = no top padding, Home's hero) on the scrolling element; never hand-roll margins/paddings for it, and set other paddings with `padding-inline`. These rules are unlayered on purpose so they beat Tailwind utilities (the build emulates layers with `:not(#\#)` boosts).
- Tailwind sizes are rem-based and TV root font is 20px: sizes in px inside virtual lists must scale with `useK()`.
